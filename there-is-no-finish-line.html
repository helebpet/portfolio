There Is No Finish Line

Spring 2025

Website, Poster

View Live Project (opens in a new tab)

Concept

"There Is No Finish Line" takes Nike's 1977 slogan and rebuilds it as a website where the typography carries the message. The site runs on p5.js across a series of linked pages, set entirely in text pulled from the original poster. Everything on screen answers the cursor, so the reading never quite settles, which is the point the slogan was making: the running is the reward, not the arriving.

Design & Implementation

Text floats, rotates, and follows the cursor, and the color shifts as you move between pages. The palette runs through yellows, oranges, and greens to convey energy and movement, and to reflect the Nike brand identity. A printed poster uses the same type and palette, so the project holds on paper as well as on screen.
